# Changelog: November 2026

## 16 Nov 2026: DataHub live check

- Land Observations key set up and tested against the live API. The nearest-station lookup, observation shape,
  field names, hPa pressure and m/s wind (DataHub glossary) all match the parser and fixtures; no code change was
  needed. [metoffice-datahub.md](../metoffice-datahub.md) updated.

## 16 Nov 2026: v2.0.0 refresh

- **Met Office moved from DataPoint (retired 2025) to Weather DataHub Land Observations.** Location is now
  `latitude`/`longitude`, resolved to the nearest station once. The poll is decoupled from the sensor interval
  (default hourly, minimum 300 s). A local daily budget and an HTTP 429 handler keep the app inside the free plan's
  360 calls/day. Mongo de-duplicates on the observation's own timestamp (`observedAt`).
- **Runs without hardware:** `sensor.type: "fake"` and `config/config-fake.json`, plus `--once` and `--config` flags.
- **Tests:** 68 pytest tests with the sensor, MQTT, MongoDB and Met Office faked, plus a real-hardware test that
  only runs on a Pi with I2C. Replaces the stray `test/test _sensor.py` script.
- **Dependencies:** `requirements.txt` cut from a 59-line `pip freeze` to the five runtime packages at current
  versions. Tooling lives in `requirements-dev.txt` (pytest, pytest-cov, ruff).
- **Security:**
  - Start-up log no longer prints the Met Office API key or the MQTT password, and the Mongo URI password is masked.
  - Error logs no longer echo Mongo exception text, which can contain the URI.
  - The example config no longer carries a real cluster hostname, LAN IP or location.
- **Config validation:** types, ranges and placeholder detection, with a clear error at start-up instead of a
  failure mid-loop.
- **Fixes:**
  - MQTT now runs the network loop, waits for CONNACK and confirms QoS 1 publishes; v1 could drop messages by
    disconnecting straight away.
  - paho 2.x callback API.
  - One Mongo client instead of a new one per call, which also fixes a client leak in the hour check.
  - Timezone-aware UTC timestamps.
  - Missing f-strings in three log lines.
  - SIGTERM is handled for pm2.
- **Repo:** `CLAUDE.md`, `docs/`, CI (pytest and ruff on Ubuntu and Windows), Dependabot (pip and actions),
  `.gitattributes`, MIT `LICENSE`, README rewritten.
